# INNOSTAA

INNOSTAA is an AI-powered desktop assistant developed in Python that combines conversational AI, internet research, computer automation, email automation, vision capabilities, and gesture-based controls into a single platform.

The goal of INNOSTAA is to create a smart personal assistant that can understand user requests, interact naturally, perform real-world tasks on a computer, and integrate with hardware devices.

---

## Features

### AI Conversation

* Natural language conversations powered by Large Language Models.
* Context-aware responses.
* Personalized memory system.

### Research Mode

* Searches the internet for up-to-date information.
* Collects information from multiple sources.
* Generates detailed summaries and reports.

### Computer Automation

* Open installed applications.
* Close running applications.
* File and folder access.
* System interaction through voice commands.

### Vision Capabilities

* Screen sharing analysis.
* Live camera understanding.
* AI-powered visual assistance.

### Gesture Controls

* Virtual Mouse.
* Gesture Whiteboard.
* Gesture-based Tic-Tac-Toe.
* Real-time hand tracking.

### Memory System

* Stores user preferences and conversation context.
* Reflective memory architecture.
* Persistent memory across sessions.

### Modern User Interface

* Interactive graphical interface.
* Real-time subtitles.
* Voice interaction support.
* Quick-access controls.

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/INNOSTAA.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file and add your API keys

```env
GROQ_API_KEY=YOUR_KEY
NVIDIA_API_KEY=YOUR_KEY
```

4. Run the project

```bash
python main.py
```
